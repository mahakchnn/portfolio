# Project Summary
This project is a modern React-based personal portfolio for Mahak Sharma, designed to effectively showcase her professional achievements, projects, and educational background. It utilizes shadcn/ui and Tailwind CSS to create a responsive and maintainable user interface. Recent enhancements include linking project cards to detailed case study pages, improving content clarity, and optimizing scroll behavior for a smoother user experience.

# Project Module Description
The portfolio consists of several functional modules:
- **Navbar**: Navigation links to different sections of the portfolio.
- **Hero**: Introduction section featuring a visual and greeting.
- **About**: Personal narrative detailing Mahak's professional journey.
- **Projects**: Display of work with a carousel for navigation, now includes links to detailed project case studies.
- **Experience**: Timeline of professional roles and contributions.
- **Education**: Academic background and qualifications.
- **Achievements**: Highlights of awards and recognitions.

- **Build Tools**: Vite, PostCSS
- **Linting**: ESLint

# Usage
To set up the project, follow these steps:
1. Install dependencies:
   ```
   pnpm install
   ```
2. Build the project:
   ```
   pnpm run build
   ```
3. Run the project:
   ```
   pnpm run dev
   ```
